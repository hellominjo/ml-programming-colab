# Machine Learning Programming Lab

> Hands-on Machine Learning labs for educational data and EdTech applications using Google Colab.

This repository contains hands-on labs and exercises from the **Machine Learning Programming** course.

## 📚 Course

**Machine Learning Programming**

The labs focus on understanding how machine learning works and exploring its applications in **educational data and EdTech**.

---

### 🎯 Learning Objectives

- Understand fundamental Machine Learning and Deep Learning concepts.
- Implement and evaluate ML models using Google Colab.
- Apply Machine Learning techniques to educational and image data.
- Explore practical applications of ML in education and EdTech.

### 🧪 Labs

The labs follow a practical learning process:

**Concept → Code → Experiment → Evaluate → Interpret**

| Topic | Description |
| --- | --- |
| Linear Regression | Understand weights, bias, prediction, and loss |
| Classification | Implement binary and multi-class classification |
| Neural Networks | Understand neural networks and backpropagation |
| CNN | Apply convolutional neural networks to image data |
| Model Evaluation | Evaluate and interpret model performance |
| Educational Data | Apply machine learning to educational datasets |

### 🛠 Environment

- Google Colab
- NumPy / pandas
- Matplotlib
- scikit-learn
- TensorFlow / PyTorch



### 💡 Machine Learning for EdTech

This repository goes beyond implementing machine learning algorithms. It explores how **educational questions can be translated into machine learning problems** and how model results can help us better understand learners and learning processes.

Example questions include:

- Can we predict student performance from learning data?
- Can we identify different patterns of learning behavior?
- Can we detect students at risk of dropping out?
- Can we classify educational content using image data?
- How can machine learning support educational decision-making?

The labs connect fundamental machine learning concepts with practical applications in **Educational Data Mining (EDM), Learning Analytics, and EdTech**.
